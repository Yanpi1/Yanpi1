## Sobre mim

**Olá, eu sou o Yan.** Desenvolvedor de sistemas e Web Designer, apaixonado por construir experiências digitais que unem **design, funcionalidade e código bem estruturado**.

Meu foco é desenvolvimento **web e mobile**, criação de interfaces **UI/UX**, integração de **APIs** e **automação**. Gosto de cuidar tanto dos detalhes visuais quanto da lógica que faz tudo funcionar.
